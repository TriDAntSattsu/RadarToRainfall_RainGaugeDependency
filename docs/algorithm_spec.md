# 解析雨量の技術資料と変更履歴

2026年11月26日確認。気象庁の[製品解説・参考資料](https://www.jma.go.jp/jma/kishou/know/kurashi/kaiseki.html)、[配信技術情報](https://www.data.jma.go.jp/suishin/cgi-bin/jyouhou/jyouhou.cgi)、[配信資料のお知らせ](https://www.data.jma.go.jp/suishin/cgi-bin/oshirase/oshirase.cgi)を起点に、両製品の生成方法・入力・提供仕様に直接関係する資料を収集した。資料名、発行・訂正日、該当ページ、確認状況は[出典台帳](../outputs/step0/source_register.csv)に記録した。以下の日付は、明記した場合を除き日本時間。

## 製品の違い

- **解析雨量（正規版）**は1 km格子の前60分雨量を30分ごとに更新する。レーダーを地上雨量で補正する。
- **速報版解析雨量**は同じ物理量を10分ごとに更新する。第24巻が説明する運用では、10分前までの50分間の解析値と、10分前に求めた雨量換算係数を用いる直近10分間の解析値を足す。
- **配布用の再解析**は後着の雨量計データや利用可否の判定を反映する。気象業務支援センターによると2014年以降のDVDは再解析版を収録し、即時配信値と異なり得る。PoCでは配信版か再解析版かを比較データに記録する。

出典：[配信仕様 No.11601](https://www.data.jma.go.jp/suishin/shiyou/pdf/no11601)、[第24巻 §7.1、§7.3.1](https://www.jma.go.jp/jma/kishou/books/yohkens/24/chapter7.pdf)、[気象業務支援センターの収録案内](https://www.jmbsc.or.jp/jp/offline/cd0100.html)。

## T02・D01に引き継ぐ確認事項

- 正規版はJMA-01の数式を起点に、JMA-05の改良を照合する。第12巻第2章（JMA-04）は参考文献と掲載ページまで特定した。原典本文は未入手。
- 速報版はJMA-09の処理図を起点に、JMA-13の過大値事例とJMA-17以降の運用変更を照合する。JMA-13で検証された個々の過大値対策の導入日は未確認。
- JMA-16は補正前データ候補を絞る根拠になる。対象の観測データが外部に提供されるか、過去事例の分を調達できるかはD01で確認する。
